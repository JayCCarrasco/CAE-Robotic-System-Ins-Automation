# INTRODUCTION

## Overview

The CAE Robotic system is an academical project that will integrate the last technologies that are neccesary for the new industry, mainly for automation and inspection tasks.
This will be a huge project that will cover all aspects of the robotic system integration, from the design to the hardware, going through all the different software, mechanical assembling, electromechanical diagrams, etc.

The different sections of the projects are:

1. Distributed architecture and common bases: ROS2 multirrobotic system, namespaces, DDS, QoS, Time Sync, Docker and simulation.
2. Advance dynamic control for balancing robot and mobile robot: PID vs LQR, fuzzy logic integration, autonomous navigation.
3. Navigation and control for drone: Modelling, control, status estimation, autonomous navigation.
4. Perception: Drone vision, SLAM, map fusion, sharing maps publication.
5. Multirrobot communication and cooperations: ROS2 DDS multidomain, MQTT / Bridge, tasks coordination.
6. Industrial integration: PLC, OPC-UA, Modbus, SCADA.
7. Backend and services: API backend, telemtry, logs, containers, cloud.
8. Frontend and cibersecurity: Web dashboard, SLAM visualization, remote control, ROS2 security, TLS, auth, hardening.

## Objective

### Main objective

The objective of the Cooperative Air - Earth Robotic System is to investigate the last technologies that are neccesary in order to implement it, creating the fundaments that will lead in a more optimize, efficient and robust system.
